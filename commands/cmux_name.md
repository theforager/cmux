Analyze the current conversation and set an appropriate cmux session title.

Requirements:
- Title should be 3-5 words describing the current task
- Use lowercase with hyphens (e.g., "fixing-auth-bug", "adding-user-dashboard")
- Be specific but concise
- Focus on what you're doing, not the project name

After deciding on a title, run:
```bash
cmux title "your-chosen-title"
```
